# DeepGram

Небольшой проект для работы с [Deepgram API](https://developers.deepgram.com/) — распознавание речи (Speech-to-Text) с помощью Python SDK.

## Структура проекта

- `StartDG.py` — пример транскрибации аудио по URL с помощью `DeepgramClient` (модель `nova-3`, язык `en`).
- `ListenSteam.py` — потоковая (streaming) транскрибация живого аудиопотока (интернет-радио) в реальном времени, с сохранением распознанного текста в файл.

## Требования

- Python 3.10+
- Пакеты `deepgram-sdk`, `python-dotenv`

## Установка

1. Создать и активировать виртуальное окружение:

   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

2. Установить зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

3. Создать файл `.env` в корне проекта на основе `.env.example` и указать в нём свой API-ключ:

   ```
   DEEPGRAM_API_KEY=ваш_ключ
   ```

## Запуск

```powershell
.venv\Scripts\python.exe StartDG.py
```

Скрипт скачает пример аудио по URL и выведет полный ответ API, а затем — только текст транскрипта.

### ListenSteam.py — потоковая транскрибация

```powershell
.venv\Scripts\python.exe ListenSteam.py
.venv\Scripts\python.exe ListenSteam.py --OutFile Session1
```

Скрипт подключается к живому аудиопотоку (интернет-радио) и распознаёт речь в реальном времени через Deepgram Streaming API. В консоль построчно выводятся промежуточные (`[Interim]`) и финальные (`[ FINAL ]`) результаты распознавания, а **финальные** фразы одновременно сохраняются в текстовый файл (по одной фразе на строку). Остановить прослушивание можно через Ctrl+C.

**Имя выходного файла:**

- Без параметра `--OutFile` файл называется:

  ```
  DeepGram[DD-MM-YYYY]_[HH-MM].txt
  ```

  где `[DD-MM-YYYY]_[HH-MM]` — дата и время запуска скрипта, например `DeepGram26-08-2026_11-09.txt`.

- С параметром `--OutFile <имя>` итоговое имя файла формируется так:
  1. Из переданного `<имя>` удаляются все символы, недопустимые в именах файлов Windows (`< > : " / \ | ? *`, а также управляющие символы).
  2. Результат обрезается до 20 символов (лишнее отбрасывается с правого края, т.е. остаются первые 20 символов).
  3. К обрезанной строке конкатенируется `[DD-MM-YYYY]_[HH-MM].txt` (дата и время запуска).

  Например, `--OutFile 'My<>Radio_Session_Name_TooLong'` при запуске 26.08.2026 в 11:09 даст файл `MyRadio_Session_Name26-08-2026_11-09.txt`.

## Безопасность: API-ключ

API-ключ Deepgram больше не хранится в коде — оба скрипта (`StartDG.py` и `ListenSteam.py`) загружают его из переменной окружения `DEEPGRAM_API_KEY` (через `python-dotenv` и файл `.env`). Файл `.env` добавлен в `.gitignore` и не должен попадать в систему контроля версий.

⚠️ Ранее ключ был захардкожен в обоих файлах и подтверждён рабочим — **рекомендуется отозвать (rotate) его** в [консоли Deepgram](https://console.deepgram.com/), даже если проект не публиковался публично.
